# Wardrobe.io
A web app where users can add clothes that they have to their wardrobe. Users can update items and delete items. Users can also post clothes for sale for the public to see. Users can coordinate outfits on the web app by combining multiple pieces of clothes. AI can make outfit recommendations based on wardrobe pieces and prompt.
